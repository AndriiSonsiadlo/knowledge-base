# Image credits

Every image under `static/img/ml/` is **generated from source** by the scripts in
`tools/figures/` — there are no third-party images in this directory, so there is
nothing here under an external licence. Each figure is original work produced for
this knowledge base and carries the same licence as the repository.

## Why generated rather than sourced

ML figures are overwhelmingly *plots*: decision boundaries, loss surfaces, ROC
curves, learning-rate schedules. Sourcing those from elsewhere gives mismatched
axes, inconsistent notation and a jumble of visual styles. Generating them means
every figure matches the page it sits on, uses one house style tuned for
legibility (large type, thick strokes, Okabe-Ito colour-blind-safe palette on an
opaque white plate), and can be regenerated whenever the text changes.

Several figures are not illustrations but **actual computations** — the
gridworld values come from running value iteration, the cliff-walking paths from
running Q-learning and SARSA, the optimizer traces from running the optimizers,
the L1/L2 tangency point from solving the constrained problem. Where a figure
makes a quantitative claim, the number in its caption is the number the code
produced.

## Regenerating

```bash
python3 -m venv .venv && .venv/bin/pip install numpy matplotlib pillow
cd tools/figures
../../.venv/bin/python gen_foundations.py     # and gen_classical, gen_deep,
                                              # gen_nlp, gen_vision,
                                              # gen_generative, gen_rl, gen_mlops
../../.venv/bin/python optimize_pngs.py       # palette-quantise for the web
../../.venv/bin/python insert_figures.py      # idempotent; wires them into docs
```

`optimize_pngs.py` cuts the directory from roughly 17 MB to 6 MB by quantising to
an adaptive 256-colour palette, and refuses to replace any file where that would
introduce visible error.

## Usage in Markdown

`<Figure>` is registered globally in `src/theme/MDXComponents.js`, so pages use it
without an import. It renders the image on a permanently light plate in both site
themes — most of these figures are dark ink on white, and would be unreadable
against the dark theme otherwise.

```jsx
<Figure
  src="/img/ml/deep/optimizer-trajectories.png"
  alt="Describe what is visible, for screen readers"
  caption="Say what the reader should take from it."
/>
```
