# Image sources — `static/img/embedded/`

Third-party figures republished under `docs/embedded/`. Every image referenced from a page in
that section has a row here, so any figure can be located, re-sourced, or removed without
searching the Markdown.

Convention: reference images through `<Figure src="/img/embedded/<folder-slug>/<name>.png" ... />`
— no `/knowledge-base` prefix; Docusaurus prepends `baseUrl` itself.

Source preference order: Bootlin training materials (CC BY-SA) → Wikimedia Commons → vendor
primary documentation → own photographs. Never a blog or image-host copy. If no properly-sourced
figure exists, use Mermaid or WaveDrom instead — that is the correct outcome.

Notes must say if an image is a crop, a frame extracted from an animation, or a screenshot of a
user interface.
