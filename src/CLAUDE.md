# src/ — theme, components, plugins

Loaded only when working under `src/`. Pure content work in `docs/` never needs this.

- **Path aliases**: `@`, `@components`, `@css`, `@lib`, `@pages`, `@plugins`, `@theme` → corresponding `src/*` dirs. Defined in **two places that must stay in sync**: `src/plugins/webpack-alias.js` (build resolution) and `jsconfig.json` (editor/types). Note `@theme` here points at `src/theme` and overlaps Docusaurus's own `@theme` namespace — `src/theme/` holds **swizzled** Docusaurus components (DocItem, Navbar, Footer, Blog*, Icon, etc.) that override the classic theme.
- **Styling**: Tailwind v4 (wired through `src/plugins/tailwind-config.js` + `postcss.config.js`) plus shadcn/ui primitives in `src/components/ui/` (Radix + `class-variance-authority` + `tailwind-merge`, helper `cn()` in `src/lib/utils.ts`). Site-wide CSS overrides in `src/css/custom.css`.
- **shadcn/ui is CLI-managed.** `components.json` configures it: `new-york` style, `@/components/ui` alias, `cssVariables: true`, and `tailwind.config: ""` because Tailwind v4 is CSS-first (there is no `tailwind.config.js`). Add components with `npx shadcn@latest add <name>` — it is non-interactive only if you answer overwrite prompts, so pipe `yes n |` to keep existing files. Design tokens (`--background`, `--primary`, `--radius`, …) live in `src/css/custom.css`; dark mode works because of `@custom-variant dark (&:is([data-theme="dark"] *))` there, which maps Tailwind's `dark:` onto Docusaurus's `data-theme` attribute. Note that current shadcn components pull the `radix-ui` mono-package rather than per-primitive `@radix-ui/*` deps.
- **Kibo UI `CodeBlock`** (`src/components/kibo-ui/code-block/index.tsx`, installed from the `@kibo-ui` registry) is a Shiki-based multi-file code block with a language switcher, filename icons, and copy button. It does **not** replace Prism for Markdown fences — it is a React component you compose by hand in `.mdx` or in `src/`. It highlights in a `useEffect`, so SSR renders an unhighlighted fallback first. The upstream `server.tsx` (RSC variant) was deleted; Docusaurus has no server components. `SiCss3` was renamed to `SiCss` to match the installed `react-icons` — re-check that if the component is ever re-added from the registry.
- **Custom plugins** (`src/plugins/`): `webpack-alias.js`, `tailwind-config.js`, and `blog-plugin.js`. The classic preset has `blog: false` — the blog is served by the custom `blog-plugin` instead (config block near the bottom of `docusaurus.config.js`).
- Components are a mix of `.js` and `.tsx`; both are accepted.
- Lint gate: `rtk run 'npm run lint'` (never the rewritten `npm run lint`), plus `npm run typecheck`.
